## SFDC: CFO investor day
**Structure.** Title (p1) → agenda (p2) → safe harbour (p3) → speaker title (p4) → **3-chapter storyline map** (p6) that **reappears before every chapter** (p20, p27) → split colour/image chapter dividers (p7, p21, p28) → chapters (p8–19 growth, p22–26 profitability, p29–33 shareholder return) → **closing KPI-tile recap of every commitment** (p34) → appendix reconciliation + non-GAAP text (p36–37).

**Visual system.** Tinted (pale) background with white rounded "cards" grouping content. Short Title-Case topic title at ~6–7% slide height; **the takeaway lives in the subtitle** directly beneath. One colour per chapter, reused on dividers and table headers. Charts are minimal: no gridlines, one max-value tick, direct labels. Footnotes are numbered superscripts, bottom-left. No page numbers (a weakness).

**Best pages.**
- p13: mirrored bars with a **tinted highlight zone** around the focus categories and the **insight sentence in a pill banner overlapping the chart card**. The best "concentration/80-20" slide in the set.
- p8, p22: chart left ~60% + **one hero number in a circle** top-right.
- p14: cohort area (focus cohorts coloured, rest grey) + a 4-row table with the key column backed by a white panel and the latest row in a dashed outline.
- p17: 3 KPIs × 3 years as 100% split bars, one hue family per KPI.
- p19: direct-labelled growth path to a target bubble, with the **headwind isolated in its own callout**.
- p23: qualitative rating table (Low/Med/High now vs future + direction-arrow column).
- p24–25: drill-down that keeps the table header + one row and adds 2 detail cards.
- p26: levers → outcome (3 lever rows + inverted "Outcome" row).
- p34: KPI tile recap (≤5 numbers, units set smaller).
- p36: clean financial table (header rule, subtotal rules, right-aligned numbers).

**Do not copy.** Logo, mascots, illustrated forest scenery, product names, the chapter slogan, brand typefaces, all financial figures, people photos.

## ADBE: investor meeting
**Structure.** Cover → welcome → safe harbour → agenda (speaker | topic rows) → strategy section (p5–14) → financial section (p15–19) → **three business-unit modules built from the same ordered slide set** (expectations → AI opportunity → monetisation → KPI proof → revenue mix → market size; p22–30, p31–39, p42–50) → financial strategy (p51–53) → **one synthesis slide** (p54) → appendix divider + reconciliations (p55–61).

**Visual system.** All-dark presenter deck; charts sit in inset rounded **cards** (~1.5% inset). Bold sentence-case titles ~5% height, top-left, one line. Big numbers: bold value, **smaller unit, light "~"/">" qualifier**, 1–2-line label. Footnotes and "Source: org, Month Year" in a fixed footer zone. No page numbers (a weakness).

**Best pages.**
- p7: KPI strip of ≤5 numbers split into two families by a divider.
- p8: banded label/value targets table with an "as of" date.
- p10: 3-layer stack (apps / models / data) with layer labels at left.
- p17: long-run stacked columns, totals labelled, **forecast year as a dashed-outline bar**, no y-axis.
- p18: 2×2 small-multiple lines with consistent colour semantics.
- p24: two-vector framing (up = more value, down = more users) linked to two text blocks.
- p28: three-stage proof (stage label → evidence tile → big number → footnoted definition).
- p29: donuts with centre total + one extracted % callout.
- p46: metric wall + supporting bar (density ceiling: keep ≤6 numbers).
- p53: combo with selective point labels + two side callouts carrying the forward-looking "so what".
- p54: synthesis funnel (keep simpler in practice).

**Do not copy.** Logos/wordmarks, product icons and names, gradients and horizon-arc art, gradient-stroke pill styling, all financials/TAM figures, UI screenshots, legal text.

## ACN: CFO investor conference
**Structure.** Dark cover (p1) → **proof up front**: two then/now/step-up tables (p2–3) → **3-pillar thesis slide doubling as agenda** (p4) → pillar sections in order with **no dividers** (p5–13) → stakeholder KPI slides (p14–16) → **closing original-vs-current guidance table** (p17). Caveats live only in per-slide footnotes.

**Visual system.** Light textured background; light-weight sans titles. Two title modes: **left-panel statement title** (short, large, content right) for high-impact or simple slides; **full-width action title** for dense ones. Many action titles take the form "gain *while* counterweight", which pre-empts the obvious objection. Monochrome purple data ramp, darkest = protagonist. **One solid "answer box" per slide** (p2, p3, p11). Structure from hairlines and tints, never boxes. Fixed footnote zone at ~86% height under a short accent rule.

**Best pages.**
- p2–3: 2-metric step-up table; only the delta column is filled.
- p4: 3-pillar thesis with 1–2 bolded words per row.
- p5: clustered bars vs benchmarks with a growth-multiple table below that reuses the series colours (benchmarks should be grey).
- p8: metric-card grid (start / end / CAGR per business).
- p11: bridging P&L table with rule weights for hierarchy and one highlight band.
- p13: capital-allocation triad (policy in grey, proof in accent; arrows would beat cubes).
- p14–16: big-number KPI row with accent captions.
- p17: guidance table with the current column shaded.
- Avoid: 3-D isometric bars (p5, 6, 10) that distort magnitude; repeating one title across slides.

**Do not copy.** Chevron logo, brand purple, cover and background imagery, proprietary programme names, typeface, isometric glyph motif, all figures.

## MCK: consulting outlook report
**Structure.** Cover → editor's note → scope/method → **key-insights page: five numbered messages** (p4) → **numbered exec summary on a tint panel** (p5–6) → five chapters, each opened by a **divider whose title IS the chapter's key message** (p7, 11, 18, 23, 27) → **chapter "Summary" tint page** → 2–5 evidence pages → back cover. The governing messages are repeated **word-for-word** at every level (pyramid).

**Visual system.**
- Full-sentence action titles on every evidence page ("X happens, driven by Y"), 1–2 lines, quantified.
- **Persistent chapter tab bar** with active state + page number in a fixed corner.
- Evidence grid: **~27% W commentary column left, ~59% W exhibit right**; text column shrinks to ~18% when the exhibit needs room.
- **Two-tier exhibit header**: chart title (what) + grey unit line (how measured), legend right-aligned on the same line.
- **One accent colour reserved for derived metrics** (CAGR, share, delta). Green/red only for direction.
- Bold-numbered footnotes then "Source:" on every chart page.
- Tint panel = synthesis; white = evidence.
- Photography only on cover/dividers.

**Best pages.**
- p9, p20, p25: chart + CAGR strip below, aligned to eras.
- p10, p20: stacked area + share-bubble columns replacing a legend.
- p13: line + small-multiple panels.
- p14–15: dot timeline of "tipping points".
- p16, p21: diagonal-split heatmap with numbered markers tied to commentary (use sparingly).
- p17, p25, p29: grey history vs coloured forecast; dashed base-year line; scenarios labelled at line ends.
- p22: bridged stacked bars + ranked contributors.
- p26, p30: waterfall with net-change bubbles, sorted by sign then size.

**Do not copy.** Logo lock-up, hatched side band, serif display face and cyan/navy identity pairing, stock photos, scenario names, all forecast figures, people and disclaimer text.

## BCG: CEO guide to AI value
**Structure.** Cover → intro with CEO questions → **labelled-row exec summary (why now / what / how)** (p3) → "why now" (maturity staircase p4, technology horizon p5) → **named three-part framework** (p6) + comparison matrix ending in an imperatives row (p7) → **templated deep-dive per element** (p8–10) → value-at-stake tiles by lever (p11) → cases as Vision → Execution → Value capture (p12–13) → effort-weighting rule (p14) threaded through trends, challenges and questions via **recurring colour bands** (p15–18) → transformation architecture (p19) → **6 numbered next steps** (p20) → contacts → back cover.

**Visual system.** Dark title band (~17% height) with a thin accent rule; **"Kicker | takeaway"** titles (kicker in accent, takeaway in white), 1–2 lines. A single-hue ramp used as a **semantic scale** (pale = low weight/older, saturated = high/newer). Grey sidebars (~33% W) hold definitions + one big stat. Big-number unit: number | thin vertical bar | 2–3-line label. "Non-exhaustive"/"Illustrative" tags top-right. Survey question shown verbatim with N=. Source bottom-left, page number bottom-right, no logo on content pages.

**Best pages.**
- p3: labelled-row exec summary.
- p4: maturity staircase + outcome stats.
- p6: three columns + unifying band.
- p7: comparison matrix + imperatives row.
- p8–10: deep-dive template.
- p11: value tiles grouped by lever.
- p12: Vision → Execution → Value capture.
- p14: proportion pillars.
- p17: big-number sidebar + barrier list with Harvey balls.
- p18: CEO-question checklist.
- p20: numbered next-steps table.
- Busiest page: p19 (simplify to 3–4 aligned layers).

**Do not copy.** Logo/series branding, particle-dust and barcode textures, exact green/charcoal styling, proprietary framework names (the three named plays, the effort-ratio rule), all survey/case figures, quotes, headshots, iceberg art.

## Cross-deck synthesis (what the skill adopts)
1. **Answer first.** The governing message or recommendation comes before the evidence (ACN p2–4, MCK p4–6, BCG p3).
2. **Action titles on evidence slides, topic titles only on navigation slides** (MCK p9–30, BCG p8–20). SFDC's subtitle-as-takeaway is the fallback when a short title is required.
3. **One storyline device carried through the deck:** a chapter map / tab bar with active state (SFDC p6/20/27, MCK nav bar), or a named framework with consistent colours (BCG p14–18).
4. **Evidence grid:** chart ≈ 60% width + commentary/so-what ≈ 30–35% (MCK workhorse, SFDC p8/22, ADBE p53).
5. **Minimal charts:** no gridlines, value axis hidden when values are labelled, direct labels, legend only when unavoidable and ordered like the stack (all five).
6. **Emphasis by contrast, not by colour count:** grey context + one accent for the protagonist; one highlight box per slide; a reserved colour for derived metrics (ACN p2/11, MCK p9/20, SFDC p13).
7. **Big-number grammar:** bold value, smaller unit, light qualifier (~, >, E), short label, footnoted definition (ADBE p7/28, SFDC p34, BCG p4).
8. **Honest data marking:** forecasts dashed/grey-history, "Illustrative"/"Non-exhaustive" tags, survey N=, estimates footnoted (ADBE p17, MCK p25, BCG p5/p8).
9. **Sources on every data slide** in a fixed footer zone; definitions and reconciliations in an appendix (all; SFDC p36, ADBE p56–61).
10. **Close with commitments or actions:** KPI recap (SFDC p34), revised outlook table (ACN p17), numbered next steps (BCG p20), decision required.
11. **Repeatable section templates** for multi-part decks (ADBE modules, BCG deep-dives).
12. **Avoid:** 3-D charts, decorative imagery on evidence slides, repeated identical titles, missing page numbers, slogan closers.
